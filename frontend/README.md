# Frontend (React + TypeScript)

This folder holds the frontend app (Vite + React + TypeScript). It is deployed to Vercel.

## Quick start

1. `cd frontend`
2. `npm install` (or `pnpm install`)
3. `npm run dev`

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (optional)
