# Functional Requirements

## Core Features (MVP)

1. Rules page (wiki-like, cross-linked)
2. Card-draw simulator (configurable deck presets and custom)
3. Timeline panel (moveId, year calculation, text entries)
4. Grid canvas (20x12 default, tile painting, note attachments)
5. Anonymous mode (localStorage)
6. Auth mode: persistent sessions + invite links (shareable)

## Premium / Future

- Multi-deck sessions
- AI-assisted generation (autogenerate earlier stages, AI player)
- Realtime collaboration (SSE/WebSocket)
