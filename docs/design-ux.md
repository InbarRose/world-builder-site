# UX & Design Standards

## Visuals

- Clean, readable layout with left-tools, center timeline, right canvas in /play view.
- Tile icons from game-icons.net (SVGs).
- Default grid 20x12; tile size configurable (default 64px).
- Accessible color contrast and keyboard accessibility.

## Components

- Reusable React components: CardWidget, DeckControls, Timeline, CanvasGrid, TileInspector, SessionModal.
